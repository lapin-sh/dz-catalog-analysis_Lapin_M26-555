# Аналитика каталога стримингового сервиса

Домашнее задание №1 по курсу «Программирование на Python».

Консольная программа собирает отчет по каталогу фильмов: средний рейтинг,
средний возраст, топ-3 по рейтингу, количество фильмов по жанрам и список
всех жанров. Все задачи из 9 этапов собраны в одном файле `catalog_analysis.py`.

## Запуск

```bash
uv run catalog_analysis.py
```

## Проверка стиля

```bash
uv run ruff check .
```
